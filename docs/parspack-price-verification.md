# تأیید پیکربندی پارس‌پک

در ۲۰۲۶-۰۹-۱۸ ساعت ۱۱:۰۶ UTC، محاسبه‌گر تعاملی [صفحهٔ رسمی سرور ابری](https://parspack.com/cloud-server) بررسی شد.

| مشخصه | مقدار مشاهده‌شده |
|---|---|
| کشور | ایران |
| دیتاسنتر | Tehran11، شناسهٔ 23 |
| سیستم‌عامل | Alma9.7-x64، شناسهٔ 2 |
| پردازنده | ۲ هسته |
| رم | ۴GB / 4096MB |
| دیسک | ۵۰GB |
| مبلغ نمایان | ۵۲٬۳۸۸ تومان در روز |

کنترل‌های محاسبه‌گر از مقادیر اولیه به ۴GB رم، ۵۰GB دیسک و ۲ هسته تغییر داده شدند. مبلغ نمایان و لینک مرحلهٔ بعد، پیکربندی یکسان داشتند:

https://my.parspack.com/server/client-area/iaas/store/cloud-server?tab=commercial&lo=23&os=2&r=4096&h=50&c=2

برآورد مقایسه برای ۳۰ روز برابر ۱٬۵۷۱٬۶۴۰ تومان است. تعرفهٔ اصلی روزانه است؛ مبلغ ماهانهٔ قراردادی یا قیمت کل سفارش تأیید نشده است. قیمت پایه در جمع معلومِ برآورد ۳۰روزه لحاظ می‌شود؛ مالیات، ترافیک، IP و بکاپ نامعلوم می‌مانند. هیچ خریدی انجام نشد.

این تأیید فقط همین پیکربندی را پوشش می‌دهد؛ سایر ردیف‌های گزارش‌شده، مناطق و سیستم‌عامل‌ها به‌طور خودکار تأیید نمی‌شوند. گزارش‌های تاریخی بازنویسی نمی‌شوند.
